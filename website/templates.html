Open a template. Make it yours.

  1. In FDO, open Create Plugin from the Plugins menu or command search.
  2. Enter a name, choose a template and select Open editor.
  3. Read README.md and SKILL.md, edit the source, and run the included tests.
  4. Compile, sign and deploy the plugin. Review its capability grants before using privileged operations.

Use the FDO CLI for terminal workflows, workspace snapshots before experiments, and the full template guide for styling and maintenance details.
