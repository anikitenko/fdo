Architecture decision / 02
AI-assisted development & recovery

Treat generated code
as a proposal, then validate it.

The model generates bounded workspace files. The application controls
acceptance, source validation, application and restore points.

01 / Plan

Workspace inventory

Safe virtual paths.
Module contracts.
Budget admission.

→
02 / Generate

Pending files

One file per request.
Retain completed work.
Bounded repairs.

→
03 / Validate

Acceptance checks

Completion + format.
Syntax + imports.
Plugin entry rules.

→
04 / Apply

Reversible change

Create restore point.
Apply workspace files.
Save resulting state.

Failure before acceptance

Incomplete output stays unapplied. Cancellation, request ceilings and deadlines stop further generation.

Why this decision

Prevent a partial model response from silently becoming the working plugin. Give the developer a recovery path.

Trade-off

More requests and validation work. Passing source checks still needs compilation, behavior tests and runtime verification.
